WORKSHOP GUIDE

วิธีใช้งาน Figura Studio

① สร้างโมเดล

พิมพ์ไอเดียหรือเลือกแม่แบบ แล้วกด Generate หรือใช้ Add Cube เพื่อเพิ่มชิ้นส่วนเอง ลากเมาส์เพื่อหมุนมุมกล้อง เลื่อนล้อเพื่อซูม

② แต่งรูปทรงและ Texture

เลือก Cube ใน Preview หรือรายการด้านล่าง แล้วเปลี่ยนตำแหน่ง ขนาด สี และเลือก Use pixel texture ไปที่ Texture Lab เพื่อวาดพิกเซล 16×16

③ แปลงรูปหรือ OBJ

Image → Pixel Cubes จะสร้างโมเดล relief จากสีพิกเซล ส่วน Mesh Tools เปิดไฟล์ OBJ แล้วแปลงเป็น Cube แบบประมาณผิวโมเดล

④ บันทึกและส่งออก

ทุกการแก้ไขบันทึกลง localStorage ในเบราว์เซอร์อัตโนมัติ หากต้องย้ายเครื่องให้กด Backup JSON แล้ว Restore JSON บนอุปกรณ์ใหม่ การล้างข้อมูลเว็บไซต์อาจลบงานได้

⑤ ส่งต่อให้ Figura

ดาวน์โหลด .bbmodel แล้วเปิดใน Blockbench (Generic Model) ตรวจ UV/Texture ก่อนนำไปวางในโฟลเดอร์ Avatar ของ Figura; เวอร์ชันนี้ยังไม่สร้าง Rig หรือ Lua Script ให้อัตโนมัติ
